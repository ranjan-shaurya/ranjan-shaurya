<!-- ======================= WORK // SELECTED PROJECTS ======================= -->
<img src="https://raw.githubusercontent.com/ranjan-shaurya/ranjan-shaurya/main/hdr_work.svg" alt="WORK // SELECTED PROJECTS" width="100%">

**[rag-qa-sys](https://github.com/ranjan-shaurya/rag-qa-sys)** &nbsp;`Python · FastAPI · Sentence-Transformers · FAISS`<br>
Retrieval-Augmented Generation QA service — upload documents, chunk + embed them, and answer natural-language questions from semantically retrieved context (pluggable LLM generation layer).

**[youtube-semantic-search](https://github.com/ranjan-shaurya/youtube-semantic-search)** &nbsp;`Python · Whisper · FFmpeg · yt-dlp`<br>
Semantic search across YouTube playlists using extracted transcripts, retrieving the most relevant videos and timestamps for natural-language queries.

**[MalwareLens](https://github.com/ranjan-shaurya/MalwareLens)** &nbsp;`Python · pefile · YARA · MITRE ATT&CK`<br>
Static malware triage engine that parses PE structure, detects packing through per-section entropy, and maps suspicious imports to ATT&CK techniques with explainable scoring.

**[NetSentinel](https://github.com/ranjan-shaurya/NetSentinel)** &nbsp;`Python · Scapy · MITRE ATT&CK`<br>
Stateful NIDS that reconstructs TCP/IP flows from pcaps to detect port scans, SYN floods, and ARP spoofing, emitting ATT&CK-mapped JSON alerts.

**[AIMpress](https://aimpress.co.in/)** &nbsp;`JavaScript · GSAP · Vite`<br>
Handcrafted gaming-community platform built with custom layouts and GSAP interactions in vanilla JavaScript, with performance and client-side security considerations.
